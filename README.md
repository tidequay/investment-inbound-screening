# investment-inbound-screening

An open-source skill that gives investors and analysts a repeatable, transparent workflow for screening inbound startup pitches against a declared investment thesis: criteria, examples, and evaluation logic are kept as versioned, reviewable files rather than ad-hoc prompts.

The skill itself lives in [`investment-inbound-screening/`](investment-inbound-screening/). See its [README](investment-inbound-screening/README.md) for setup and usage.

**Note:** `thesis.json` contains fictional example screening criteria shown for demonstration purposes only. They do not represent the repository author's investment thesis or any real fund's mandate.
